# Поэтапный пересмотр сайта — завершён

Все страницы и расширения согласованы владельцем. 2026-09-26 макеты перенесены в Astro/MDX: главная, Schiffman с анимацией, статья EN/RU, About, Contacts, Images и Digest.

Digest публикуется без чужих изображений: короткие пересказы, ссылки на источники и собственная типографическая обложка. Images использует три фотографии владельца и нативный попап без внутренних страниц.

Прототипы остаются локальными и исключены из Git. Действующие правила — в [editorial-layout.md](editorial-layout.md), редактирование — в [README](../README.md). Сборка и проверка не равны публикации: завершение релиза подтверждается отдельно на GitHub Pages.
